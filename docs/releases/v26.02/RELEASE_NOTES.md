# Hawwwker 货客 v26.02 发布说明

发布日期：2026-11-02 · 上一版本：v26.01

这一版先站在普通用户的角度把 v26.01 完整用了一遍（综合 6.8 / 10 分），再对照 Google AI 购物、ChatGPT 购物研究、Amazon Rufus、Keepa、什么值得买 / 慢慢买、淘宝 / 京东 / 拼多多的 AI 搜索等竞品，做了针对性的改动。主要扣分在"等结果太久、页面层级太深、只比标价、看不出算不算好价、上手门槛"，本版逐项处理。评测与竞品分析全文见 release-evidence 包里的《用户评测与竞品分析-v26.02.md》。

## 新功能

**搜索与结果**

- **渐进式结果**：每个平台搜完就先显示结果，标"AI 核对中"。AI 逐条核对完成后，卡片原地更新，页面不跳动。
- **到手价**：识别运费、包邮、券后价、满减和百分比优惠券，按"券后价 + 运费"计算到手价。预算筛选和价格排序都按到手价算，卡片上用"包邮 / 含运费 / 券后"标签说明构成。
- **价格判断**：根据本机记录的历史价格给出"历史最低 / 近期低位 / 价格正常 / 偏高 / 数据积累中"，并写明依据（几天内几次观测、最低价、中位价）。追踪项上同样显示。
- **粘贴商品链接**：在搜索框粘贴任意平台的商品链接，自动识别平台、标题和价格。可以一键"全网找同款比价"，也可以"追踪这个价格"（已追踪时直接跳转）。
- **"不相关"反馈**：AI 判断错了可以一键把某条标为不相关，它会被折叠起来；同一需求或监控以后自动排除，也可以撤销。
- **复制比价清单 / 导出 CSV**：一次搜索的结果可以复制成纯文本清单直接发给别人，也可以导出表格（含到手价、运费、券后价、价格判断）。

**追踪与提醒**

- **提醒直达"去购买"**：到价、降价提醒带商品链接，点一下打开商品页。不会自动下单，下单仍由你本人确认。
- **我的售价（商户）**：追踪竞品时可以填自己的售价，卡片上直接显示"比竞品贵 / 便宜 x%"。
- **价格走势**：没选商品时自动挑历史最多的 3 个，图表不再是空的；数据少时会说明原因。

**上手与平台**

- **自动检测本机模型**：检测到 Ollama 或 LM Studio 时，引导和 AI 设置页都提供"使用本机模型（免费）"，一键填好并测试。
- **按所在地区推荐平台**：引导时根据时区和语言预选平台并说明理由，同时标出每个平台"需登录 / 建议登录 / 免登录"。
- **平台检测**：「平台目录」可以对单个平台或全部已启用平台做一次真实的小搜索，报告能否识别结果、价格是否解析成功。发布前验证国际站规则也用这个功能，命令行同样可用：`hawwwker.exe --selftest-sites 报告.md [平台…]`。

## 界面简化（功能一个没少）

- 侧栏从 13 个入口精简为 5 个：**搜索 · 追踪 · 洞察 · 平台 · 设置**（另有 Copilot）。二级页面移到顶部标签页，点一级入口会回到上次停留的标签。所有原有地址照常可用，`Alt+1…5` 可以快速切换。
- 搜索页出结果后，指令框、进度面板、AI 计划、AI 总结都收成一行（点开即展开），结果第一屏就能看到。筛选条只保留"匹配度 / 排序 / 视图"，其余条件收进"筛选"按钮，按钮上显示已生效的条件数（新增"包邮""好价"两个条件）。
- 追踪页的 4 张统计卡合成一条细统计栏，兼作筛选。监控每行精简为两行，平台标签折叠成"N 个平台"。
- 平台页分为「账号与登录 | 平台目录（高级）」两个标签。账号页默认只看已启用的平台，可切换"待处理 / 全部"并支持搜索。搜索模板编辑折叠到"编辑模板"里。
- 设置的 4 个页面合成一个设置区，用 4 个标签切换。
- Copilot 默认显示按角色挑的 3 个常用技能，其余放进"技能"下拉。新增"Copilot 看到"一行，写明它能读到哪些上下文，可以一键附上当前搜索、追踪或监控。
- 铃铛弹层精简为最近 5 条加"查看全部"。

## 上版本遗留问题

| 遗留问题 | v26.02 处理 |
|---|---|
| Windows 安装包需在本机生成 | 本版直接提供 Windows x64 安装包和便携版 |
| 自动化浏览器的调试端口可被本机其他程序连接 | 默认改用 `--remote-debugging-pipe` 管道通信，不再开任何端口；只有管道启动失败才回退到随机本地端口，界面上显示当前模式 |
| 程序被强制结束后，自动化浏览器可能残留 | Windows 用 Job Object、Linux 用 `PR_SET_PDEATHSIG`，主程序退出后浏览器一定随之退出 |
| 国际站规则未在真实站点验证 | 新增平台检测工具（界面按钮 + 命令行），可在真实网络上逐站验证并生成报告 |
| 汇率只有一个来源 | 新增第二汇率源（open.er-api.com），ECB 失败时自动切换，两个都失败才用缓存或内置表 |

## 其他改进

- 便携版的数据保存在 exe 旁边的 `Hawwwker-data` 文件夹，可以整个文件夹拷走；所在位置不可写时，自动改用系统应用数据目录。
- 网页预览版是单个 `index.html`，双击就能在浏览器里体验全部界面（使用模拟数据）。
- Rust 最低版本要求升到 1.87（管道通信用到 `std::io::pipe`）；clippy 开启 `-D warnings` 无告警。
- 数据库自动迁移到 v2：新增运费、券后价、我的售价、提醒链接和反馈表，旧数据保留。

## 已知限制

- **安装包和便携版未做代码签名**：首次运行时 Windows SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"即可。可以用 SHA256SUMS.txt 核对文件。
- **Windows 程序是交叉编译的 GNU 版本**，没有在真实 Windows 桌面上打开过界面（构建环境无法运行 WebView2）。建议首次安装后到「平台 · 平台目录」点"检测已启用平台"，确认各站点在你的网络和登录状态下工作正常。
- **国际站点规则仍标为 Beta**：检测工具已提供，但发布环境访问不了这些网站，还没有逐站跑过真实检测。识别失败时，运行日志和检测报告会写明原因，可以在「平台目录」改搜索模板。
- 便携版和安装版的数据各自独立，不会自动合并。
