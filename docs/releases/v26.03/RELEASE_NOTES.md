# Hawwwker 货客 v26.03 发布说明

发布日期：2026-11-02 · 上一版本：v26.02

本版逐条处理了 v26.02 使用中反馈的问题：登录状态不稳、明明登录了却搜不出来、登录还没完成窗口就被关掉、平台之间的登录互相牵连。同时把搜索重做成 10 个阶段，加入了商品风险、店铺可信度和评论分析；Copilot 加了内置提示词，并能直接操作软件。

## 一、登录（反馈 1–4）

**登录判定更严格，不会再"还在登录就自动关闭"**

自动识别"已登录"必须同时满足四个条件：

1. 出现了只有真正登录后才会有的 Cookie，且与打开窗口时不同；
2. 登录窗口已经离开登录页、验证码页、短信验证页、滑块页和二次验证页；
3. 以上两条连续 3 次检查都成立；
4. 在后台打开该平台的账号页，确认没有被跳回登录页。

最后一步没通过时，窗口保持打开，提示"还在登录中…完成后会自动识别"。确认成功后提示"登录成功，3 秒后自动关闭窗口"；如果窗口仍停在验证页面，则不会关闭。点"我已登录"也走同样的检查。

**登录状态保存得更牢**

- **退出时优雅关闭浏览器**：先让浏览器自己关闭并把 Cookie 写入磁盘，最多等 7 秒，之后才强制结束。上一版刚登录就关软件，可能会丢失登录。
- **加密会话备份**：每个平台的登录会话都会加密备份在本机（Windows 用系统 DPAPI，其他系统用 ChaCha20-Poly1305）。备份时机：确认登录后、保活时、每 30 分钟、退出时。浏览器启动或搜索前发现登录 Cookie 丢失，会自动从备份恢复（不恢复已过期的）；恢复后会重新验证一次。
- **状态以验证为准**：只有打开账号页验证通过、或搜索成功之后，才显示"已登录"。只有 Cookie 时显示"未检测"，搜索前会先验证。退出某个平台或"清除全部登录"时，备份一并删除。

**选了指定平台，登录前不能搜索**

- 在平台选择里点选的平台，或在指令里点名的平台（例如"京东 淘宝 小红书"），只要有需要登录但没登录的，就会弹出"先登录再搜索"窗口。
- 窗口里每个平台都可以直接"登录"或点"我已登录"，状态实时更新。
- 其余选择：
  - **不登录也搜**：仅限"建议登录"的平台，结果可能较少；
  - **移除未登录平台**：用剩下的平台继续搜索；
  - **取消搜索**。
- 搜索前会做预检：超过 20 分钟没验证过的平台，会先在后台验证一次（最多 3 个同时进行）。
- 后端同样会拒绝"指定了但没登录"的搜索，返回需要登录的平台列表。AI 自动选择的平台如果需要登录但没登录，会在"平台判定"阶段跳过，并在进度面板里给出"去登录"按钮。

**取消平台之间的互联**

- 每个平台都是独立账号，登录、退出、状态互不影响（例如闲鱼和淘宝不再互相带动）。
- 闲鱼只使用 goofish.com 的会话。
- 退出某个平台时，如果某个 Cookie 域名仍被另一个已登录的平台使用，会保留并说明原因。

**其他登录修复**

- 去掉了未登录时也存在的"假登录 Cookie"，例如淘宝 `lgc`、闲鱼 `tracknick`、1688 `__cn_logon__`。
- 修复 Amazon 登录后跳回 `?ref_=nav_signin` 时永远识别不到登录的问题。
- 验证或评论读取超时时，后台标签页一定会被关闭。
- 「账号与登录」页新增：
  - "登录体检"：一键验证全部需要登录的平台；
  - 每个平台显示"已验证 · x 分钟前"和"会话已备份"。

## 二、搜索流程重做（反馈 5–7）

搜索现在分 10 个阶段，进度面板逐一显示，并给出每一步保留了多少商品，例如"抓取 102 → 粗筛 11 → 风险 10 → 评论 5 件 → 最终 10"：

1. **理解需求**：AI 分析品类、品牌、型号、预算、成色和是否要正品。
2. **平台判定**：用你指定的平台，或由 AI 按品类和地区挑选（二手找闲鱼 / eBay / Kleinanzeigen，正品敏感优先官方和自营），并说明跳过了哪些平台、为什么。
3. **多平台搜索**：每个平台搜完先出结果。
4. **粗筛**：按需求匹配度筛选（规则 + AI）。
5. **商品风险分析**：
   - **正品风险**：高仿、原单、A 货、复刻、1:1 等字样；品牌商品价格远低于同款中位价。
   - **功能和规格不符**；二手 / 翻新 / 配件。
   - **其他信号**：无销量、无评价、海外代购。
   - 结果为风险分 0–100，分低 / 中 / 高三档，并列出每条依据。
6. **店铺可信度**：识别旗舰店、官方店、平台自营（京东自营、Amazon 自营）、专卖店、专营店、企业店、个人卖家、小工作室、海外代购、二手商家、第三方卖家，结合评分、开店年限和粉丝数给出可信度 0–100。
7. **评论检索**：在后台打开排名靠前商品的详情页，读取商品评分、评论数、好评率、评论原文、店铺评分（描述 / 服务 / 物流）和开店年限。遇到需要登录或验证码时，会写明"读不到的原因"，而不是报错。读取结果缓存 24 小时。
8. **评论分析与匹配**：AI 归纳优点、缺点和风险信号（假货、质量、售后），并对照你的需求（例如"多条评论提到降噪好"）。
9. **最终细筛**：综合分 = 匹配 40% + 风险 20% + 店铺 15% + 评论 15% + 价格 10%，缺少的项按比例重新分配权重。不符合需求的最高 30 分，仅"相关"的最高 70 分，高风险的最高 55 分。高风险商品默认折叠，并写明原因。
10. **总结**：推荐款按综合分选出，并参考风险和评论。

**检索深度**：「设置 · 通用」和搜索框旁可选：

- **快速**：不读评论；
- **标准**：默认，读前 6 件的评论；
- **深入**：读更多商品，并读店铺评价。

定时监控最多读 3 件。

**商品标签和风险评分**（反馈 7）

- 每个结果先显示店铺类型标签（旗舰店 / 官方店 / 平台自营 / 专卖店 / 专营店 / 企业店 / 个人卖家 / 小工作室 / 海外代购 / 二手商家 / 第三方卖家），再显示包邮、历史最低 / 好价、高销量、好评多、风险高等标签。
- 风险徽章显示等级和分数，悬停可看依据。
- 你提到的"个人自营"含义不唯一，所以拆成两种：个人卖家标为"个人卖家"，平台自己经营的标为"平台自营"。

**抓取精确度**（反馈 6）

- 为淘宝 / 天猫、京东、拼多多、闲鱼、1688、各 Amazon 站点、各 eBay 站点、idealo、AliExpress、Temu、Walmart、Best Buy、乐天、Mercari、Kleinanzeigen 加了专用识别规则。识别不到 3 条时，自动回到通用识别方式。
- 新增读取的信息：店铺名、店铺徽章、销量（月销 / 已售 / 人付款 / sold / verkauft）、评分、评论数、发货地。
- 标题会去掉"广告 / Sponsored / Gesponsert"等前缀；能读取页面里的结构化商品列表（JSON-LD）。
- 遇到滑块或"Robot Check"页面时，平台状态变为"等你操作"，在设置允许的情况下弹出窗口，由你本人完成验证。

**界面**

- 结果卡新增：标签行、风险徽章、评论分（★ 评分 · 条数 · 好评率）、店铺名和销量；增强阶段进行中时标注"评论读取中…"。
- 详情页新增：综合评分构成、店铺、风险分析、评论分析（优点、缺点、风险信号、与需求的对应、代表评论、店铺评价）。
- 排序新增"综合推荐分"和"低风险优先"。
- 筛选新增"风险等级"和"店铺类型"（可多选）。
- 导出的清单和 CSV 新增：标签、风险等级 / 分数、评论分、综合分。

## 三、Copilot（反馈 8–9）

**内置提示词**

**送礼礼节**：

- **不知道对方口味**：不推荐茶叶、酒、咖啡豆、香水、护肤彩妆、要选尺码的衣服鞋子、口味类食品；改送他爱好周边的好物件（爱喝茶 → 茶具：盖碗、旅行茶具、公道杯、建盏；爱咖啡 → 手冲壶、磨豆机）。
- **明确知道偏好**（例如"他只喝武夷岩茶"）：才推荐消耗品。
- 还覆盖：
  - 送礼禁忌：钟、伞、梨、鞋、刀剪、镜子、绿帽子、菊花、喜事避开白黑包装、数字 4；
  - 关系与场合；
  - 按到手价控制预算；
  - 包装和附言；
  - 方便退换；
  - 国外的习惯差异。

"给我选 500 元内送爱喝茶的朋友的礼物"现在会推荐茶具方向，说明为什么不送茶叶，并最多追问一个问题。

**其他知识**：

- 购物：到手价、正品渠道、假货信号、大促节点（618、双 11、黑五、Prime Day）；
- 商户：行业判断框架、选品和定价思路、广告法用语。

**直接操作软件**

- 你明确让它做事时（"用 app 搜索…"、"帮我去京东搜…"、"打开追踪页"、"切换深色"、"只看精确匹配"），Copilot 会直接执行，并在对话里显示"自动执行 · 已开始搜索"。
- 发起搜索时，对话里有实时进度卡片，可以取消或查看。搜索完成后，Copilot 会自动点评结果（推荐哪件、哪件便宜但风险高），不需要你再输入。
- 指定了平台且需要登录时，会先弹出登录窗口。
- 安全限制：
  - 能自动执行的只有搜索、页面跳转、修改设置和整理结果；
  - 打开外部链接、加入追踪、创建监控、取消搜索只会给出按钮，由你自己点；
  - 外部链接必须来自当前结果或已知平台域名，防止商品标题里夹带的文字诱导它打开别的网站；
  - 没有任何下单或付款操作。

## 已知限制

- **规则未经真实站点验证**：各平台"登录后才有的 Cookie"、账号验证页地址、专用识别规则、评论页结构，都是按公开页面结构编写的，构建环境访问不了这些网站。部分平台的登录识别名单是推测的，包括小红书 / RedNote（`web_session` 访客也有，主要靠账号页验证判断）、微博、闲鱼、1688。安装后建议先到「平台 · 平台目录」点"检测已启用平台"，再到「账号与登录」点"登录体检"。
- **Amazon 账号页**：有时即使已登录也会要求再次输入密码，这种情况会显示"未验证"，搜索不受影响。
- **Windows 版本**：交叉编译的 GNU 版本，未做代码签名，界面未在真实 Windows 桌面上打开过。
- **模型 ID**：新的模型 ID 晚于部分资料的更新时间。如果服务商再次改名，请在 AI 设置页点"获取模型列表"。
