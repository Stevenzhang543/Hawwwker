# Hawwwker v26.01 用户评测与竞品分析

> 评测方式：跳出开发者视角，以"第一次装上这个软件的普通用户"身份完整走一遍：安装 → 引导 → 连接 AI → 登录平台 → 搜索 → 看结果 → 追踪 → 监控 → 洞察 → Copilot → 设置。
> 环境：v26.01 桌面版（真实 Rust 内核 + 内嵌界面）+ 浏览器预览版（模拟数据，覆盖 32 个平台与 90 天价格历史）。
> 评分：10 分制，6 分以下为"明显影响使用"。

## 1. 功能评分

| # | 功能 | 分数 | 好的地方 | 不足 / 不方便 |
|---|---|:-:|---|---|
| 1 | 首次引导 | 7 | 步骤清晰、画面精致；AI 连接不通过不能继续，避免"用了才发现不能用" | **AI Key 是唯一门槛却没有零成本路径**（本机已装 Ollama 也要手填）；平台一步给出一长串开关，新手不知道该开哪些、哪些要登录 |
| 2 | 输入需求 | 8 | 一句话说清品牌、预算、平台；示例按角色给 | **不能直接粘贴商品链接**（最常见的比价起点："我在淘宝看到这个，哪里更便宜？"）；地区分段 + 平台选择是两次额外决策 |
| 3 | 搜索过程 | 6 | 每个平台的状态都看得到，能取消、能显示浏览器 | **结果要等全部平台 + AI 校验 + 总结做完才出现**，4–8 个平台常常要等 30–120 秒，期间只能看进度条 |
| 4 | 结果列表 | 6 | AI 匹配度、换算价、"也在 N 个平台"很实用 | **结果在页面第 4 屏**（指令框 → 进度 → 总结 → 计划 → 筛选条 → 结果）；筛选条 8 个控件挤在一行；**只比标价，不算运费和券后价**；**看不出这个价格算不算好价**；AI 判错时没法纠正；不能分享/导出这次比价 |
| 5 | AI 总结 | 8 | 一句话结论 + 推荐款 + 注意事项，比自己看几十条快 | 放在结果前面但最后才出来；推荐款没有"为什么不是第二名" |
| 6 | 商品详情 | 8 | 价格历史 + 同款比价 + 目标价线 | 新商品历史只有 1 个点，图表空荡荡且没解释；"联系商家"只是打开商品页 |
| 7 | 价格追踪 | 7 | 目标价进度条、迷你走势、粘贴链接追踪 | 4 张统计卡占了半屏；到价提醒后还要自己找商品；看不出"现在入手合适吗" |
| 8 | 定时监控 | 7 | 信息全：新增、最低价、目标价、上次/下次 | 每行 4 组信息 + 一长串平台标签，扫一眼很累 |
| 9 | 提醒中心 | 6 | 按类型筛选 | 与右上角铃铛重复；提醒里没有"去购买"一键直达 |
| 10 | 价格走势 | 6 | 多线对比、十字线 | 要先手动勾选才有图；数据少时是空图 |
| 11 | 市场分析 | 7 | KPI、平台中位价、价格带、AI 报告 | 对消费者意义不大，却和消费者功能平级展示 |
| 12 | 账号与登录 | 8 | 状态准确、关窗口即取消、共享账号有提示 | 32 个平台全部列出，找自己要登录的要滚动 |
| 13 | 平台目录 | 6 | 能改搜索模板、加自定义平台 | 宽表格 + 网址模板对普通用户很吓人，应作为"高级" |
| 14 | 设置 | 6 | AI 配置页完整（预设、测试、用量） | 在侧栏占 4 个入口 |
| 15 | Copilot | 8 | 技能 + 流式 + 一键动作 | 8 个技能芯片挤满抽屉顶部；看不出它"看到"了哪些上下文 |
| 16 | 整体导航 | 5 | 分组清楚 | **侧栏 13 个入口 + 角色选择 + Copilot + 状态**，二级菜单永远展开，信息密度过高 |
| 17 | 速度 | 5 | — | 浏览器模拟天生比 API 慢，且没有"先出部分结果" |
| 18 | 可靠性 | 7 | 取消、超时、断点回放都可靠 | 国际站规则未在真实站点逐一验证 |

**综合：6.8 / 10**。核心能力（跨国内外平台 + AI 核对）是独有的，扣分主要在"等待时间、页面层级、到手价、价格好坏判断、上手门槛"。

## 2. 竞品

| 产品 | 类型 | 强项 | 相对 Hawwwker 的短板 |
|---|---|---|---|
| Google AI Mode 购物 | 搜索引擎 AI | 500 亿级商品图谱、即时出结果、到价提醒、美国区代下单、AI 打电话问门店库存 | 以美国为主；不覆盖淘宝/京东/拼多多/闲鱼/小红书；含广告位 |
| ChatGPT 购物研究 | 通用 AI | 追问需求、读评测、生成选购指南 | 无价格追踪与提醒；不覆盖国内平台；看不到你登录后的会员价 |
| Perplexity 购物 | AI 搜索 | 带来源的对比、部分商家可直接下单 | 无历史价格与提醒；国际为主 |
| Amazon Rufus | 平台内 AI | 365 天价格历史；"降到 X 自动下单"（24 小时可取消） | 只限 Amazon |
| Keepa / CamelCamelCamel | 价格历史插件 | 多年 Amazon 价格曲线、降价提醒、浏览器插件 | 只限 Amazon；无 AI；不跨平台 |
| PayPal Honey | 优惠插件 | 自动找券、Droplist 降价提醒 | 联盟返利争议；不覆盖国内 |
| idealo / Geizhals | 欧洲比价站 | 商家报价聚合、价格提醒 | 区域性；无 AI；不覆盖国内平台 |
| 什么值得买 / 慢慢买 | 国内比价 | 全网比价、30–180 天历史价、**到手价（含券、国补、会员价）**、降价提醒 | 只覆盖国内；以返利/内容驱动 |
| 淘宝 AI 万能搜 / 京东京言 / 拼多多 AI 搜索 | 平台内 AI | 平台内商品库大、价格趋势、看评价 | **只看自家平台，无法跨平台比价**（36氪称之为"硬伤"）；同一商品给出矛盾价格 |
| Prisync（商户） | 竞品调价 SaaS | 竞品价格监控、调价建议 | 付费、需逐个录入竞品链接 |

行业背景：上海市消保委调查显示 84.56% 的受访者用过 AI 购物，但只有 16.06% 认为"商品匹配准确"——这正是 Hawwwker"AI 逐条核对"要解决的问题。

## 3. Hawwwker 的位置

**优势（继续放大）**

1. **国内 + 国际一次搜**：淘宝/京东/拼多多/闲鱼/小红书 与 Amazon/eBay/idealo/Temu 在同一张比价表里，按汇率换算。没有任何竞品做到。
2. **在你自己的登录会话里运行**：看到的是你账号的会员价、地区价；数据留在本机。
3. **AI 逐条核对**：配件、二手、不同代际被标出并折叠，直击"匹配不准"。
4. **三种角色 + Copilot 动作**：同一套数据服务消费者、商户、分析人员。

**短板（本版针对性补齐）**

| 短板 | 竞品参照 | v26.02 改动 |
|---|---|---|
| 等待时间长 | Google 即时出结果 | **渐进式结果**：每个平台搜完立刻显示（规则初判），AI 核对完成后原位更新 |
| 只比标价 | 什么值得买"到手价" | **到手价**：识别运费、包邮、券后价、满减；按到手价排序与比较 |
| 不知道算不算好价 | Rufus 365 天、Keepa 曲线 | **价格判断徽章**：历史最低 / 近期低位 / 正常 / 偏高，附依据（N 天内 M 次观测） |
| 不能从链接开始 | 拍立淘、慢慢买 | **粘贴商品链接**：识别平台 → "全网找同款比价" 或 "追踪这个价格" |
| 上手门槛 | 零配置 | **自动检测本机 Ollama**；引导按所在地区推荐平台，并标出哪些无需登录 |
| AI 判错无法纠正 | — | **"不相关"反馈**：一键折叠并记住，同一需求/监控以后自动排除 |
| 提醒后还要找商品 | Rufus 自动下单 | **提醒直达**：到价提醒带"去购买"，一键打开商品页（不自动下单，下单仍由你确认） |
| 不能分享 | — | **复制比价清单 / 导出本次结果 CSV** |
| 商户缺少定位视角 | Prisync | **我的售价**：追踪项可填自己的售价，显示相对市场最低价的位置 |

## 4. 界面简化方案（功能不减）

1. 侧栏只保留 5 个一级入口：**搜索 · 追踪 · 洞察 · 平台 · 设置**（+ Copilot）。二级入口改为页面顶部的标签页。
2. 搜索页：有结果后指令框收成一行；进度面板完成后收成一条状态栏；计划默认折叠为一行摘要；筛选条只留"匹配度 / 排序 / 视图"，其余收进"筛选"按钮。
3. 追踪页统计卡改为一条细统计栏；监控行精简为两行。
4. 平台目录作为"平台"页里的"高级"标签；设置 4 个入口合并为一个页面的 4 个标签。
5. Copilot 技能收成"技能"下拉 + 3 个常用。

## 5. 上版本遗留问题

| 遗留问题 | v26.02 处理 |
|---|---|
| Windows 安装包需在本机生成 | 交叉编译出 Windows x64 便携版与安装包，随发布提供 |
| 调试端口可被本机其他程序连接 | 改用 `--remote-debugging-pipe`（管道通信，不开端口）；管道启动失败时才回退到随机端口 |
| 国际站规则未在真实站点验证 | 提供实站验证工具，并在 Windows 实机上对主要国际站跑验证 |
| 汇率离线 | 增加第二汇率源，失败自动切换 |
